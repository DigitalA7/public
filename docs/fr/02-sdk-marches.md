# SDK et lecture des marchés

Le SDK fournit les abstractions nécessaires pour interagir avec le programme Solend et lire les marchés. Une intégration doit distinguer les données de compte, les paramètres de marché et les transactions construites. Les valeurs affichées restent dépendantes du RPC, du cluster et de la fraîcheur des comptes.
