# Architecture du monorepo

Le dépôt public de Solend regroupe un SDK TypeScript, un client léger et un liquidateur dans un espace de travail partagé. Cette organisation sépare les primitives d’intégration, l’interface simplifiée et les opérations de liquidation. Le parcours lit les responsabilités à partir des dossiers et du README, sans exécuter les outils.
