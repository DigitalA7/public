# Limites et périmètre

Ce parcours couvre la structure publique du monorepo Solend, le SDK, le client léger et le liquidateur. Il ne constitue pas un audit du protocole ni une validation des paramètres de production. Aucune installation, compilation ou exécution de test n’a été réalisée ; les scripts du dépôt sont seulement des pistes de vérification ultérieure.
