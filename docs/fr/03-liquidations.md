# Liquidations

Le module liquidator sert de base à des bots communautaires chargés d’identifier les positions liquidables et de préparer les opérations nécessaires. Une stratégie de liquidation doit vérifier la dette, le collatéral, les seuils et les coûts avant toute soumission. Le dépôt ne garantit pas à lui seul la rentabilité ni la disponibilité d’un marché.
